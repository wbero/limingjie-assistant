# 黎明界助手 1.0.16 产品测试更新说明

日期：2026-10-10　版本号：1.0.16（10016）　状态：测试版

## 本版更新

1. **调整幽灵领主 EX 配队。** 按魔法伤害评估前排生存，优先一名前排搭配远离前排的队友，减少近身成员和额外坦克。失败重试及换治疗时也考虑站位；可用后排不足时尽量降低风险，并在推荐理由中提示。
2. **增强卡顿和事件页面诊断。** 下载日志包时增加 Android 版本、设备、分辨率、DPI、权限，以及最近约一小时的助手进程 CPU/内存与截图状态。事件页面记录 OCR 缓存失效原因、识别文字、按钮可用状态；点击记录派发与回调耗时，方便定位卡住原因。
3. **包含已合并的星辉吐息流程修复。** 破晓之星遗物「星辉吐息」将败北改判为胜利后，正确识别只有「伤害报告」和「下一步」的战败页，继续遗物结果及回地图流程，不消耗战斗重试次数。

## 建议重点测试

| 场景 | 操作与预期 |
| --- | --- |
| 幽灵领主首次编组 | 同时有高评分近战及较低评分远程时，应优先选择更少近身成员的阵容，推荐理由包含隔离前排说明。 |
| 幽灵领主失败重试 | 首战失败后换阵容，第二次失败后的治疗替换也应尽量保持前排隔离，避免重复已失败的整队。 |
| 角色不足及其他 EX | 后排不足时仍按现有角色推荐并提示风险；核对其他 EX、普通战斗和 Boss 编组未出现回退。 |
| 星辉吐息 | 战败后由星辉吐息改判胜利，核对两键战败页能够进入下一步、关闭遗物结果并回地图。 |
| 事件页卡住 | 暂停并立即下载日志 ZIP，提供停住时间、事件名称和当时截图，核对日志包包含新增诊断文件。 |
| 较长时间运行 | 运行一段时间后导出日志，检查 CPU/内存采样及捕获状态；电脑端负载另行提供。 |
