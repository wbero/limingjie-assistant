# 黎明界助手 1.0.14 产品测试更新说明

日期：2026-09-25　版本号：1.0.14（10014）　状态：测试版

## 本版更新

1. **新增多渠道服支持。** 新建账号时可选择 B 服、小米、华为、vivo、OPPO、九游、4399、MuMu 或应用宝。助手会按当前选中账号打开对应游戏客户端；缺少客户端时会提示，不会改用其他已安装客户端。渠道服的「登录账号 / 密码」分别填写 `uid` / `access_key`。
2. **横屏界面更紧凑。** 缩小标题栏、文字与卡片间距，让账号、权限和黎明界页面在单屏显示更多内容。
3. **降低误点与连续运行故障。** 「返回标题」按钮需要连续多帧识别才会点击，减少把商店等正常页面误判为掉线的风险。无障碍手势完成后及时释放回调持有的任务对象，缓解连续多局后的内存增长。

## 建议重点测试

| 场景 | 操作与预期 |
| --- | --- |
| 账号与客户端 | 分别新增 B 服和渠道服账号，切换账号后核对启动的是对应客户端；未安装对应客户端、服务器值无法识别时应明确报错，不能操作其他客户端。 |
| 登录与单局 | 在已配置的 B 服、小米、华为、vivo 环境中，验证登录、读取当前开局、启动并完成一局；记录客户端版本、模拟器和分辨率。 |
| 横屏显示 | 检查账号、权限、黎明界及策略设置页的文字、按钮、滚动和点击区域，尤其是小屏或非 1920 × 1080 分辨率。 |
| 会话恢复 | 正常商店页不应触发「返回标题」；真实掉线弹窗持续出现时应能恢复。连续运行多局时留意内存、卡死和误点。 |

## 已知问题与测试边界

- **Boss 等挑战页长战斗：** 从「挑战」按钮开战后的等待保护修复仍在 PR #12，未进入本版；战斗超过约 30 秒可能因路线阶段超时而停机。测试时请记录诊断包。
- **4399 连续多局：** 被顶号返回标题后可能出现未识别的 4399 用户协议弹窗，自动恢复会卡住；目前仅确认可以登录。
- **运行中切换服务器：** 编辑当前账号的服务器会改变自动化目标。请先停止任务，再切换账号或服务器。
- 已有渠道服验证覆盖雷电模拟器 9、1920 × 1080 下的小米、华为、vivo；OPPO、九游、MuMu 渠道、应用宝尚未实机验证。多渠道改动合并后，B 服账号仍需回归。手机及其他尺寸也需要验证。

反馈问题时，请附应用版本、游戏客户端与服务器、设备/模拟器、Android 版本、分辨率、复现步骤及脱敏诊断日志包；勿提交账号密码、访问令牌或验证码。
