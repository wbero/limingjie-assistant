# 战斗结算等待

- 仅在 START_BATTLE 或 BATTLE_START_CHALLENGE（挑战页的“挑战”按钮，不经编组页直接开打，例如 Boss 三连战）动作成功执行且回调仍属于当前会话时，启动独立 5 分钟等待。单独看到挑战页、选人、动作被拒绝/暂停/过期均不触发。
- 已明确识别为 BATTLE_IN_PROGRESS 时也能进入等待，支持战斗中接管。
- 等待期间的 UNKNOWN、加载、战斗帧不走普通 30 秒未知超时，也不执行立绘、奖励或最终结算动画补点。原始页面识别仍保留，界面消息显示“等待战斗结算（最长5分钟）”。
- 计时从成功动作回调（接管时从首个确认战斗帧）开始，战斗/加载/未知反复切换以及重复启动通知不会续期。达到 5 分钟后，在下一识别帧停止并保留诊断。
- 明确结算、奖励、地图或其他页面退出等待并交还原流程；点击后编组页或挑战页允许最多 3 秒残帧，持续仍在编组页则交还原有重试上限处理。下一场战斗重新计时。
- 停止、重启、会话失效、重新登录均清除等待上下文。
- 单独命中菜单或 AUTO 战斗控件（>=0.45）不直接判为战斗、不自动获得 5 分钟等待，但会禁止 UNKNOWN/事件动画的兜底点击，包括旧动画分支和新增立绘补点。

本地验证：固定时限、识别抖动、无开始证据、旧编组残帧、结算/地图退出、下一场战斗、会话重置以及部分战斗特征拦截。实际战斗由用户在模拟器验证。
