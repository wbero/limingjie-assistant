# 手机端策略设置

入口：黎明界右上角「策略设置」。全屏独立编辑页，五个折叠分组；滑块支持拖动，加减按钮支持逐点微调。恢复默认需要确认，并仍需保存；退出未保存编辑会提示。

## 生效与存储

- 全局配置，所有账号共用；本地 SharedPreferences 持久化，写入成功后才显示保存成功。
- 每次启动识别/自动执行读取一份不可变快照，重新创建评分、选人、事件、遗物、商店决策器。运行中保存只影响下一次启动，不要求重启 App。
- 默认值保持本次改动前的生产评分配置。损坏或无效的保存数据回退默认值；不修改内置角色数据文件。

## 配置范围

| 分组 | 可调整项 |
| --- | --- |
| 评分 | 玩家评分占比；角色头像列表及个人评分；系统伤害、生存、功能、阵型、协同相对权重（自动归一化，不能全部为零） |
| 选人 | 第二队、第三队部署权重；重复纯掩护/纯治疗的基础扣分 |
| Boss编组 | 多队/单队编组；是否优先纯物理/纯法术；单队失败后是否切多队及重新挑战次数 |
| 战斗失败 | 3 次失败后是否自动重刷开局 |
| 遗物 | 基础目标 1–4 层；前期加分截止区域 0–5；转追削弱的最低层数和落后容忍量 |
| 遗物优先级 | 主追印记顺序（留空用内置顺序） |
| 商店 | 是否购买遗物；是否刷新；从哪个区域允许刷新 |
| 开局 | 每个公会开局三槽位与候选顺序 |
| 事件 | 普通、极难战的估计胜率，仅用于奖励估值 |

第一队权重固定 100%；遗物 15 层收益档位、安全识别条件和游戏事实不开放修改。角色资料完整性只作为评分提示，不再阻止自动选人或编组；头像可靠性与实际一号位为 T 的条件仍需满足，缺失站位不会被假定为后排。商店仍只买遗物，不买角色商品，不提供金币余额预算（当前没有可靠余额输入）。

## 角色头像与个人评分

- 评分分组内进入「角色头像与个人评分」，按名称、版本或 ID 搜索，可切换「仅看已修改」。头像按精确角色 ID 关联，完整名称用于区分同名不同版本；缺图显示占位框。
- 每行显示原评分与个人评分；已修改头像框高亮。点击编辑 0–100 整数分，支持键盘和加减微调，可恢复单角色原评分。
- 编辑应用到策略草稿，返回上一级点击「保存配置」后持久化，下次会话生效；全局恢复默认也会清除个人评分。
- personalScore 独立于原 userScore/userRatingCount，参与选人及编组的 effectiveUserScore，不改变数据库事实或资料完整性。不填写则沿用原评分；0 分是有效个人评分。
- LazyColumn 仅加载可见头像；离开主线程串行解码，图像限制到 128 像素，使用页面级 2 MiB 缓存，无需下载。

## 手动验收（用户执行）

1. 打开设置，检查窄屏、横屏、系统大字体下分组和底部保存按钮可达；旋转后草稿保留。
2. 修改一项后返回，应出现放弃提醒；取消应保留编辑。
3. 保存后退出重进、重启 App，值应保持。恢复默认后不保存退出，原保存值应保持。
4. 运行中保存新配置，当前任务不变；停止后重新启动，评分解释/遗物选择/商店行为采用新配置。
5. 关闭购买，下一次启动进入商店应退出；关闭刷新后不得请求刷新。
